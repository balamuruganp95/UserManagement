# Release Management Plan

## Versioning
Use Semantic Versioning:
`MAJOR.MINOR.PATCH`

## Release Checklist
- Requirements approved.
- Code reviewed.
- Unit tests pass.
- Integration tests pass.
- Security checks pass.
- Build succeeds.
- Database changes reviewed.
- Environment variables verified.
- Deployment completed.
- Smoke tests pass.
- Monitoring verified.
- Rollback plan available.

## Rollback
Every production release must have a documented rollback strategy for both application and database changes.
