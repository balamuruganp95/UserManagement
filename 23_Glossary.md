# Glossary

**Authentication:** Verifying who a user is.

**Authorization:** Determining what an authenticated user can do.

**RBAC:** Role-Based Access Control.

**Role:** A named collection of permissions.

**Permission:** An allowed action on a resource.

**JWT:** JSON Web Token used to represent authenticated claims.

**CRUD:** Create, Read, Update, Delete.

**MFA:** Multi-Factor Authentication.

**Audit Log:** Record of security/business actions.

**API:** Application Programming Interface.

**NFR:** Non-Functional Requirement.

**FRD:** Functional Requirements Document.

**PRD:** Product Requirements Document.

**SRS:** Software Requirements Specification.
